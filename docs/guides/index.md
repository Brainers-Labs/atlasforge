# Guides

Task-oriented walkthroughs. Each one ends with something you can see.

| I want to... | Guide |
|---|---|
| Run the whole thing in Colab or a notebook | [Use it in Colab or a notebook](colab-and-notebooks.md) |
| Score a model on my own data | [Evaluate a model](evaluate-a-model.md) |
| Find out whether a change helped, and where it hurt | [Compare two models](compare-two-models.md) |
| Catch data problems before they spoil a result | [Validate your data](validate-your-data.md) |
| Turn voice notes into text, or measure speech accuracy | [Transcribe speech](transcribe-speech.md) |
| Run N-ATLaS on my own machine or server | [Serve N-ATLaS](serve-n-atlas.md) |
| Reproduce the published AfroBench-LITE suite | [Benchmark with AfroBench-LITE](benchmark-with-afrobench.md) |
| Fine-tune N-ATLaS for my domain | [Fine-tune with QLoRA](fine-tune-with-qlora.md) |
| Publish my adapter responsibly | [Publish a model card](publish-a-model-card.md) |

The usual order for a fine-tuning project is: **validate** your data, **evaluate** the base model, **fine-tune**, **evaluate** the adapter, **compare**, then write the **model card**.
