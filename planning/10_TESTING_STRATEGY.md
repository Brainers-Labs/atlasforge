# Testing Strategy

## Layers

| Layer | Runs | Needs | Covers |
|---|---|---|---|
| Unit | every commit (CI) | CPU only | normalization, metrics, bootstrap, dataset parsing, chunking maths, config precedence, error mapping, CLI arg parsing |
| Contract | every commit (CI) | CPU only | `openai` backend against recorded HTTP fixtures (vLLM response shapes, including errors) and a fake `local` backend |
| Tiny-model | every commit (CI) | CPU, public tiny models | end-to-end `eval`/`transcribe` wiring using `sshleifer/tiny-gpt2`-style and `openai/whisper-tiny`, **never presented as N-ATLaS results** |
| Live | manual / nightly on GPU box | `HF_TOKEN`, gated access, GPU | real N-ATLaS + all 4 ASR models: generate, transcribe, eval starter packs |

The default `pytest` run needs no credentials, no GPU and no gated weights. Live tests are marked `@pytest.mark.live` and skipped unless `ATLASFORGE_LIVE=1`.

## Must-have tests for correctness claims

- Normalization: Yoruba precomposed vs combining diacritics score identically. Tone-insensitive strips tones but keeps base letters. Hausa hooked letters are preserved.
- WER/CER match jiwer reference values on fixed fixtures.
- Bootstrap: fixed seed gives a deterministic CI. The CI is zero-width when base equals candidate.
- Chunking: a 95 s input produces correct window boundaries and overlap merge without duplicated words on fixtures.
- Resume: an interrupted eval resumes without re-running completed IDs.

## Integration evidence (feeds the NAIC submission)

The live run writes `evidence/live_<date>.md`: model repo IDs and commit SHAs, hardware, sample I/O per language, starter-pack scores and timings. It is generated by `scripts/live_smoke.py`, not written by hand.
