# NAIC Submission Checklist

Target: submit **Sun 11 Oct**. Hard deadline Mon 12 Oct, 11:59 PM WAT.

## 1. Working artefact
- [ ] Public GitHub repo, tag `v0.1.0`
- [ ] `pip install atlasforge` works from PyPI in a fresh venv (Linux, macOS, Windows)
- [ ] `doctor`, `run`, `transcribe`, `eval`, `compare` work against real N-ATLaS
- [ ] Example reports committed under `examples/reports/`
- [ ] Colab notebook(s) run top-to-bottom

## 2. N-ATLAS integration evidence
- [ ] `evidence/live_<date>.md` generated by `scripts/live_smoke.py`: repo IDs + commit SHAs of all 5 NCAIR1 models, hardware, sample I/O per language, timings
- [ ] Architecture diagram showing NCAIR1 models as the only models in the core path
- [ ] Short "How AtlasForge integrates N-ATLAS" doc (backends, loading, routing)
- [ ] Statement: no other foundation model used. CI tiny models are for wiring tests only.

## 3. Real-world validation
- [ ] ≥2 external testers with complete records (`validation/testers/T0X.md`), dated, release-tagged
- [ ] Consent recorded for any names, quotes or recordings used
- [ ] Round 1 → Round 2 improvement: issues found, issues fixed
- [ ] Measured metrics (time to first eval, success rate, usability score). No invented numbers.
- [ ] Any tester-produced reports (e.g. a Problem 03 team's compare report), with permission

## 4. Technical documentation
- [ ] Docs site live: quickstart (A/B paths), licences & access, guides (eval, compare, ASR, fine-tune, vLLM), CLI & API reference, dataset format, metrics & normalization, troubleshooting
- [ ] Hausa quickstart (reviewed by a named person)
- [ ] README, CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, CHANGELOG, LICENSE
- [ ] Benchmark pack PROVENANCE files with licences

## 5. Demo video (3–5 min)
